# DeepSeek Figure Studio：让科研图可修改、可追溯

**把数据、图形和修改记录放进同一个工作台，减少数据更新后重新排版的负担。** 项目面向需要反复修改论文图的研究生、科研人员和科研 Agent 开发者。以下描述对应 2026-11-12 本地候选版本，新增优化尚未发布到 GitHub。

## 解决什么问题

科研绘图难在持续修改：更新数据后还要重调颜色和字号，拼图后发现标签太小，AI 改图又可能影响已确认内容。本项目希望让“从数据出图—局部修改—组合—导出”保留同一份可编辑工程，便于核对和返工。

## 怎样解决

CSV/Excel 导入后，用户先确认字段映射和统计含义，再创建图表。局部样式与数据绑定分开保存；AI 提交受约束的编辑操作，先显示前后预览，再由用户应用、撤销。数据来源、修改历史和导出文件可追溯。

工作台、DSH 插件与 MCP 共用 FigureDocument、EditOp 和 SVG 渲染核心，支持 SVG、PDF、PNG 等输出。项目重点是把可编辑性与可追溯性落实到交互流程中。

## 已验证的效果

本次审查抽查 **23 项测试，全部通过**，其中三组合成案例实际生成并解码了导出文件：

- 统计图更新为 12 行数据后保留系列颜色，并触发统计声明重审；89 mm、300 dpi 的 PNG 宽 1052 px。
- XPS 使用提供的拟合列，验证峰样式和反向轴；89 mm、600 dpi 的 PNG 宽 2103 px。
- 四面板只更新第 (d) 图，其余三图元素保持不变；183 mm、300 dpi 的 PNG 宽 2162 px。

这些结果证明对应流程可运行，**不能换算为画质或效率提升百分比**。[验证记录与限制](next-improvement-plan.md)

本项目的开发贡献是工作台、受控编辑操作、数据绑定展示覆盖及宿主接入的工程集成；不把通用科研绘图方法称为独创。

当前仍需修复期刊检查误报和峰标注 ID 保留，补验干净环境安装、原生窗口及真实模型流程；共享坐标和共享图例尚未自动化。项目不恢复图片中的原始数据、不自动做 XPS 峰分解，也不保证期刊合规。许可证与第三方资产声明仍待完善。
